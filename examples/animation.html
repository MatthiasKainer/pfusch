Animating with pfusch

Four lifecycle attrs — keep, mount, unmount, exit — plus plain CSS. Every section here is asserted by e2e/tests-animation/animation.spec.js.

1. An imperative engine inside a pfusch node

keep hands the node's children to StepStateIcon; mount builds it once, unmount tears it down. The parent only ever changes an attribute — the engine node is never rebuilt, so window.__mounts stays at 1.

2. Enter and exit for a list

Entering rows animate from @starting-style; leaving rows get exit: 'leaving', so pfusch keeps them in place until the animation finishes.

3. A function exit (Web Animations API)

The handler starts the animation itself and pfusch awaits it. Under prefers-reduced-motion it starts nothing, so the panel disappears at once.

4. Reordering with View Transitions

pfusch moves the existing nodes, so a document.startViewTransition wrapper is all a FLIP needs. Nothing in the core.
