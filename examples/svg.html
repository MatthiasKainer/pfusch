SVG with pfusch

html.svg(...) renders in the SVG namespace, so the browser paints it and CSS transitions run on the real nodes. Asserted by e2e/tests-svg/svg.spec.js.

1. A declarative, animated ring

Only a class on <svg> and the dash offset change between states. The <circle> is never rebuilt, so the CSS transition keeps running and window.__ringMounts stays at 1.

2. foreignObject returns to HTML

Children of foreignObject are created in the HTML namespace again, so a plain <div> lays out and wraps as usual.
